FAQ

Questions we get asked

Do I need GSP access?
No. TaxSphere works with files you already have — GSTR-2B JSON from the GST portal and your purchase register from Tally or Excel. GSP integration is optional and only on Enterprise.
Is the AI-generated notice reply safe to submit?
TaxSphere generates a draft. Every draft marks sections needing CA review with [REVIEW REQUIRED]. The CA is always responsible for reviewing before submission. TaxSphere is an operational tool, not a legal advisor.
How does the Tally connector work?
Tally Prime exposes a built-in HTTP API on port 9000. TaxSphere connects directly — no ODBC driver needed. Client enables HTTP server in Tally (F12 → Advanced Configuration). We provide a one-page guide.
Is client data stored in India?
Yes. All data on AWS Mumbai (ap-south-1). AES-256 at rest, TLS 1.3 in transit. Each CA firm's data completely isolated. We do not sell or share any data.
What happens after the free trial?
Choose a plan and pay via Razorpay. If you don't upgrade, account goes read-only — previous reconciliations visible but no new ones. No data deleted. No credit card required during trial.
